Role Management

Define network access policies and micro-segmentation rules.

How Roles Work

Roles define what a user is allowed to access once connected to the VPN. Use ALL for full access, specific ports like 80,443 for web access, or specific IP:Port combinations like 10.8.0.50:5432 for strict micro-segmentation. Claviger automatically translates these into Linux Kernel rules.
